# 🚀 Nguyen Anh Phi - AI Engineer Portfolio

Welcome to the source code of my personal portfolio! This is a modern, high-performance, and highly interactive website built to showcase my projects, skills, and academic background in Artificial Intelligence and Software Engineering.

## ✨ Key Features
- **Premium Smooth Scrolling:** Powered by [Lenis](https://lenis.studiofreight.com/) for a fluid, physics-based scroll experience with inertia.
- **Advanced Animations:** Built with [Framer Motion](https://www.framer.com/motion/) featuring spring-physics hover effects, a full-screen initializing preloader, and an automated Image Carousel.
- **Data-Driven Architecture:** All content (skills, projects, personal info, terminal commands) is decoupled from the UI and centralized in a single `portfolioData.js` file for effortless updates.
- **Glassmorphism & Dark Mode:** A sleek, Vercel/Linear-inspired aesthetic with deep space themes, glowing nodes, and backdrop blurs.
- **Interactive Terminal:** A fully functional, retro-style terminal bio that responds to commands like `whoami`, `projects`, and `contact`.

## 🛠️ Tech Stack
- **Framework:** React.js + Vite
- **Styling:** Vanilla CSS3 (Custom Properties, Glassmorphism, CSS Grid/Flexbox)
- **Animations:** Framer Motion
- **Scroll Engine:** @studio-freight/react-lenis
- **Icons:** Lucide React & SimpleIcons

## 💻 Local Development

If you'd like to run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YourUsername/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   *The site will be running at `http://localhost:5173`.*

## 📂 Project Structure
- `/src/data/portfolioData.js`: 🧠 The "brain" of the portfolio. Edit this file to update all text and links across the site.
- `/src/components/`: Reusable React components (Navbar, Hero, SkillsSection, ImageCarousel, etc.).
- `/src/index.css`: Global design tokens, color variables, and core styles.
- `/public/`: Static assets like images and logos.
